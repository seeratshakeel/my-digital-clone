

\# My Learning Journey



\## Topics I Have Learned



\- Topic 1: Database Management \& Design

I have learned how to design and manage relational databases in MySQL. I learned to create tables, use primary and foreign keys, indexing for fast searching, and triggers for auto-generating queue tokens in my clinic project.



\- Topic 2: Web Development (Frontend \& Backend)

I have learned to build responsive websites using HTML, CSS, Bootstrap 5, JavaScript, and PHP. I can create user-friendly dashboards for both patients and doctors and connect them with the backend.



\- Topic 3: Queue Management \& Concurrency Control

This was a specific topic from my project. I learned how real-world queue systems work, how to handle two users booking at the same time, and how to use database transactions and locking (UPDLOCK) to avoid duplicate tokens.





\## Current Learning



\- What I am learning:

Currently I am learning AJAX for live queue updates without page refresh, and I have started learning React.js to rebuild my clinic system on MERN Stack.



\- Why I am learning it:

I am learning it because my current system needs to be faster and more modern. AJAX will make the patient queue live, and React will make the system more scalable and ready for real clinics.



\- What I find interesting:

The most interesting part is seeing real-time data. When a patient books a token and the doctor's dashboard updates instantly without refreshing - that live connection between frontend and database is very exciting for me.





\## Challenges



\- A difficult topic I studied:

The most difficult topic was Concurrency Control in MySQL. When two patients tried to book the last available token at the exact same second, my system was creating duplicate tokens.



\- How I tried to understand it:

I first watched tutorials on transactions, then I read MySQL documentation about locking. I tested it many times on my local XAMPP server by opening two browsers at once. I asked my teacher and finally solved it using BEGIN TRANSACTION and UPDLOCK.



\- What I learned from the experience:

I learned that a real-world system is not just about design, but about handling worst-case situations. I also learned to be patient, to test everything multiple times, and that errors are the best teachers.
