\# My Projects and Learning Experience



\## Project 1

\- Project name:Smart Clinic Appointment and Queue Management System

\- Purpose:To create a single platform for small clinics that combines patient records, doctor availability, online appointment booking, walk-in registration, and live queue token tracking to reduce patient waiting time

\- Tools used:HTML, CSS, Bootstrap 5, JavaScript, PHP, MySQL, VS Code

\- What I learned:I learned how to design a relational database with proper indexing, how to use triggers for auto token generation, and how to handle concurrency control when two patients request a token at the same time. I also learned responsive design with Bootstrap

\- Challenges I faced:The main challenge was to avoid duplicate token generation for simultaneous requests. I solved it by using database transactions and UPDLOCK. Another challenge was making the live queue display responsive for both mobile and desktop



\## Project 2

\- Project name:Online Student Attendance \& Performance Portal

\- Purpose:To develop a web portal for teachers and students where attendance and academic performance can be managed online with separate dashboards for both roles

\- Tools used: React.js, Node.js, MongoDB, Bootstrap 5, Git \& GitHub

\- What I learned:I learned how to create REST APIs, how to manage authentication for different user roles (teacher/student), and how to connect frontend with MongoDB database. I also improved my skills in component-based design

\- Challenges I faced:Managing role-based access was difficult, and handling real-time attendance data was challenging. I learned to use JWT for secure login and optimized database queries to make the portal fast
